# PocoERP 部署文档

目标环境：Ubuntu 22.04（内网服务器 192.168.1.14），MongoDB 副本集已在本机运行（27017，认证库 crawler）。

架构：

```
浏览器 ──80──> Nginx ──静态──> web/dist（Vue 构建产物）
                  ├──/api/────> Node(Express) 127.0.0.1:3000 ──> MongoDB 127.0.0.1:27017
                  └──/uploads/─┘  (PM2 守护，开机自启)
```

## 一、首次部署（全自动）

在本地项目根目录执行（凭据走环境变量，不进代码库）：

```bash
# 1) 上传 setup 脚本到服务器
node scripts/scp-put.js deploy/setup-server.sh ~/setup-server.sh

# 2) 在服务器上执行（Mongo 凭据与 sudo 密码通过环境注入）
node scripts/ssh-run.js \
  "chmod +x ~/setup-server.sh && \
   SUDO_PASS=<sudo密码> MONGODB_USERNAME=<mongo用户> MONGODB_PASSWORD=<mongo密码> ~/setup-server.sh"
```

脚本会完成：安装用户级 Node 20 → 克隆代码到 `~/pocoerp` → 生成 `server/.env`（含随机 JWT_SECRET，权限 600）→
安装依赖 → 构建前端 → PM2 启动并配置开机自启 → 安装配置 Nginx → 配置每日 03:30 mongodump 备份（保留 14 天）。

## 二、日常更新

本地推送代码后，在服务器执行：

```bash
~/pocoerp/deploy/deploy.sh
```

（git pull → npm ci → 前端构建 → pm2 reload → 健康检查）

## 三、手动部署步骤（脚本失效时参考）

1. **Node 20**：脚本安装到 `~/apps/node20`（npmmirror 二进制包）。其他机器可换 nodesource/官方包。
2. **代码**：`git clone https://gitee.com/luopub/pocoerp.git ~/pocoerp`
3. **环境变量**：`cp server/.env.example server/.env`，填写 Mongo 连接与 `JWT_SECRET`（生产必须修改），`chmod 600`。
4. **后端**：`cd server && npm ci --omit=dev`
5. **前端**：`cd web && npm ci && npm run build`
6. **进程守护**：`npm i -g pm2 && pm2 start ecosystem.config.js && pm2 save && pm2 startup`
7. **Nginx**：`deploy/nginx-pocoerp.conf` → `/etc/nginx/sites-available/pocoerp`，软链到 `sites-enabled`，删除 default，`nginx -t && systemctl reload nginx`。
8. **备份**：`crontab -e` 加 `30 3 * * * ~/pocoerp/deploy/backup.sh >> ~/backups/pocoerp.log 2>&1`

## 四、运维要点

- **健康检查**：`curl http://127.0.0.1/api/health` 应返回 `{"status":"ok"}`。
- **日志**：`pm2 logs pocoerp`；文件在 `~/pocoerp/logs/`。
- **备份**：`~/backups/pocoerp/<时间戳>/`，保留 14 天。恢复：
  `mongorestore --uri="mongodb://<user>:<pass>@127.0.0.1:27017/?authSource=crawler" --db pocoerp <备份目录>/pocoerp`
- **上传文件**：`~/pocoerp/uploads/` 不在 Mongo 备份内，需另行备份（可加入 cron 的 tar 打包）。
- **初始账号**：admin / admin123，**首次登录后请立即在「系统设置 → 用户管理」中重置密码**。
- **安全**：MongoDB 仅监听内网；如服务器暴露公网，务必开启 Mongo 认证之外的防火墙限制，并给 Nginx 配 HTTPS。
